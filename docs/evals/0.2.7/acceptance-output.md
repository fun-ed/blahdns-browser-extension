# 0.2.7 verification

This preview fixes startup configuration when session cleanup fails and preserves tab counters across repeated loading events. Cleanup failures remain visible in the UI. Known request IDs distinguish interrupted navigations; loading after completion starts a new boundary. The popup browser test uses timer polling while its tab is in the background.

No permission, dependency, settings-schema or collection-scope change. Statistics remain opt-in. Failure to clear session data can leave temporary entries until browser restart; the warning remains visible and disabled collection does not return activity. Tab counters can include unload requests issued after navigation starts; separate document histories and observed page URLs are not retained.

Limits: unsigned temporary Firefox installation, untested minimum browser versions and native permission dialogs, forced-crash rather than natural-idle recovery, incomplete proxy transport coverage and no CAPTCHA guarantee. DoH setup remains manual. Chrome/Brave request feedback requires an unpacked installation. No store submission or CRX signing is included.
