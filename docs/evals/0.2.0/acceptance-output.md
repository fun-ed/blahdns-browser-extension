## Verification history

[Run 001](check-run-001.md) records the old single-key storage fixture failure and correction. `browser-run-001.json` and `browser-run-002.json` retain incomplete browser runs. Chromium needed to wait for the native media-change event after clearing emulation. Firefox needed to reactivate the options tab through the extension tabs API after closing the popup; BiDi privileged-context activation is unsupported, as recorded in `browser-run-003.json`. `browser-run-004.json` is the succeeding focused Firefox run. The final combined browser output supersedes those failed/incomplete runs.

## Limits

Unsigned XPI supports temporary development loading. Ordinary Firefox permanent installation requires Mozilla signing. No AMO/store submission, CRX key generation or signing is claimed. The native optional proxy prompt and declared minimum browser versions are not covered. Firefox BiDi OS color emulation and live-browser storage-failure injection are not claimed; corresponding shared behavior has unit/Chromium evidence. HTTP/2, HTTP/3, QUIC, full proxy transport coverage and CAPTCHA outcomes remain outside this matrix. Existing DNS diagnostic behavior is unchanged; prior SG/DE query results remain in the 0.1.0 evidence.
