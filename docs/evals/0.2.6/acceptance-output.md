Independent standards/spec review found no blocking issue after the startup, rollback, IPv6 and navigation fixes. The Chromium package retains the shared Firefox module graph; avoiding its unused dependency parsing is deferred, without a browser-startup performance claim.

Counters describe actions observed in a tab after its latest navigation reset. Outgoing unload requests issued during the transition can be included. Separate document histories and observed page URLs are not retained. Requests queued before a reset or arriving for closed tabs cannot recreate old activity. Invalid/unreadable Firefox settings explicitly report that request filtering was not initialized; existing native rules remain unchanged. A valid configuration that cannot build the JavaScript matcher attempts native DNR fallback and makes statistics unavailable until repaired.

Limits: unsigned temporary Firefox installation, untested minimum browser versions and native permission dialogs, forced-crash rather than natural-idle recovery, incomplete proxy transport coverage and no CAPTCHA guarantee. DoH setup remains manual. Chrome/Brave request feedback requires an unpacked installation. No store submission, CRX signing or remote deployment is included.
