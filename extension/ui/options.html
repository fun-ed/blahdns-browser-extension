Filtering scope

Privacy controls

WebRTC IP addresses

This is a global browser setting. It may affect calls and other real-time connections.

Browser fingerprinting

This is a global setting. Only Firefox provides native resistFingerprinting. Extension APIs in Chrome and Brave cannot provide the same protection.

About audio, Canvas, WebGL, and time zone

This extension does not inject noise or alter JavaScript fingerprints. Firefox native resistFingerprinting can change some signals globally. Chrome and Brave do not offer an equivalent native control here. Use browser privacy settings where available and set your time zone in the operating system or browser. Audio, Canvas, WebGL, and time zone data can still differ. A header change cannot make them consistent.

No setting can guarantee that a site will accept a CAPTCHA or other risk check.

Language header

This changes the HTTP header only. It does not change JavaScript language, Client Hints, operating system language, or worker data.

User-Agent header

This changes the HTTP User-Agent header only. It does not change JavaScript, Client Hints, TLS, or worker data. A mismatch may break a site.

DNS and proxy

The DNS check sends a fixed DNS-over-HTTPS POST query. It does not change system DNS.

BlahDNS DNS-over-HTTPS

Set up DoH manually in your browser

This extension does not control DNS for the browser, operating system, or other apps. Open the browser Secure DNS or DNS over HTTPS settings. Choose a custom provider and enter an endpoint:

Singapore
https://doh-sg.blahdns.com/dns-query
Germany
https://doh-de.blahdns.com/dns-query

Firefox: Settings → Privacy & Security → DNS over HTTPS. Chrome and Brave: Settings → Privacy and security → Security → Use secure DNS. Menu names may change between versions.

HTTP/2, HTTP/3, and QUIC support depends on the browser, server, and network path. This extension does not force a protocol or intercept all UDP and QUIC traffic.

Proxy

This version does not store proxy user names or passwords. When the proxy is enabled, the browser asks for proxy permission before saving.

Enter one destination domain per line. Both proxy lists use domain-tree matching: example.com and *.example.com include the apex and all subdomains.

Proxy scope uses the destination host name, not the tab host name. Pausing filtering does not bypass the proxy. UDP and QUIC support depends on the browser and proxy type.

Local data

Settings and counters stay on this device. This extension does not use telemetry or cloud sync.

Statistics

Counters store totals only. They do not store browsing history or domain history.
